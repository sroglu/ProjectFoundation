# MathTools
Scalar math, interpolation, running statistics, and a PID controller in a pure-C# core, plus a Unity layer for vector/rect/bounds/random math.

**Key classes:** `ScalarMath`, `Interpolation`, `RunningStatistics`, `PidController` (core); `VectorMath`, `RectMath`, `BoundsMath`, `IntVectorMath`, `RandomMath` (Unity layer)
**Assembly:** `PFound.Utilities.MathTools` (core), `PFound.Utilities.MathTools.Unity` (engine layer)
**Tier:** core (with an engine `.Unity` layer)
**Depends on:** `.Unity` layer references `PFound.Utilities.MathTools`
